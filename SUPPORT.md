# Dukungan (Support)

- Dokumentasi & contoh: `README.md` dan `CHANGELOG.md`
- Pertanyaan penggunaan: GitHub Discussions / issue dengan label `question`
- Bug: issue memakai template Bug Report
- Kerentanan keamanan: JANGAN lewat issue publik — lihat `SECURITY.md`
- Pengguna corporate/enterprise: sertakan versi (`aicutad --version`),
  versi Node (`node --version`), OS, dan profil kebijakan (`policy.json`)
  yang dipakai saat melaporkan masalah (tanpa API key tentunya).
